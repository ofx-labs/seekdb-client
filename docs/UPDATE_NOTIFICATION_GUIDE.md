# 版本更新通知 - 使用指南

## 功能概述

seekdb-client 插件的版本更新通知功能可以在插件更新后自动展示更新日志，让用户第一时间了解新版本的功能和改进。

## 如何工作

### 自动检测流程

```
插件启动
    ↓
读取 package.json 获取当前版本
    ↓
读取全局状态中的上次版本
    ↓
版本是否变化？
    ├─ 是 → 显示更新日志面板
    │        ↓
    │   更新全局状态中的版本记录
    │
    └─ 否 → 跳过通知
```

### 更新日志界面

更新日志界面包含以下元素：

1. **头部区域**
   - 插件图标（🗄️）
   - 标题："seekdb-client 已更新"
   - 欢迎语
   - 版本变化徽章（旧版本 → 新版本）

2. **内容区域**
   - 解析并格式化的 CHANGELOG.md 内容
   - 支持的元素：
     - 标题（H2, H3, H4）
     - 列表（带项目符号）
     - 粗体文本
     - 分隔线
     - 引用块

3. **操作按钮**
   - **开始使用**：关闭更新日志面板
   - **查看完整日志**：在编辑器中打开 CHANGELOG.md

4. **页脚**
   - GitHub 仓库链接
   - 反馈和建议入口

## 使用方法

### 方法一：自动显示（首选）

1. 更新插件到新版本
2. 重启 VS Code 或重新加载窗口
3. 更新日志面板会自动显示

### 方法二：手动查看

任何时候想查看更新日志：

1. 打开命令面板：
   - macOS: `Cmd + Shift + P`
   - Windows/Linux: `Ctrl + Shift + P`

2. 输入：`seekdb: 查看更新日志`

3. 按 Enter 执行命令

### 方法三：通过设置禁用

如果不想看到自动通知：

1. 打开 VS Code 设置
2. 搜索：`seekdb.updateNotification.enabled`
3. 取消勾选该选项

禁用后仍可通过命令面板手动查看更新日志。

## 界面样式

### 颜色方案

更新日志界面完全采用 VS Code 的原生配色方案：

- **背景色**: 编辑器背景色
- **前景色**: 编辑器文本色
- **强调色**: 按钮主题色
- **边框色**: 面板边框色
- **链接色**: 文本链接色

### 响应式设计

- 桌面端：最大宽度 900px，居中显示
- 移动端：自适应宽度，按钮垂直排列

### 视觉元素

- **版本徽章**：
  - 旧版本：灰色背景
  - 新版本：蓝色背景（主题色）

- **更新类型图标**：
  - ✨ 新功能
  - 🐛 Bug 修复
  - 📝 改进

## 开发者指南

### 更新 CHANGELOG

为确保更新通知正确显示，请遵循以下格式：

```markdown
## Changelog

### `v1.0.0` — 2025‑01‑26

#### ✨ New

- **功能名称**
  - 功能描述 1
  - 功能描述 2

#### 🐛 Fixes

- 修复问题 1
- 修复问题 2

#### 📝 Improvements

- 改进 1
- 改进 2

---
```

### 测试更新通知

1. 使用测试脚本修改版本号：
   ```bash
   ./scripts/test-update-notification.sh
   ```

2. 选择测试场景：
   - 小版本更新 (patch)
   - 中版本更新 (minor)
   - 大版本更新 (major)

3. 编译并启动调试：
   ```bash
   npm run compile
   # 按 F5 启动调试
   ```

4. 在扩展开发主机中验证更新通知

5. 测试完成后恢复原版本：
   ```bash
   ./scripts/test-update-notification.sh
   # 选择选项 4
   ```

### 清除版本记录

如需重新测试或重置状态：

1. 打开命令面板
2. 输入：`Developer: Open Extension Host Storage`
3. 找到并删除键：`seekdb.lastVersion`

## 常见问题

### Q1: 为什么首次安装时不显示更新通知？

A: 首次安装时系统无法确定"上一个版本"，因此不会显示更新通知。这是为了避免给新用户带来困扰。

### Q2: 如何修改更新日志的样式？

A: 编辑 `src/services/UpdateNotificationService.ts` 中的 `getWebviewContent` 方法，修改 CSS 样式。

### Q3: 可以支持更多的 Markdown 语法吗？

A: 可以。修改 `parseChangelogToHtml` 方法添加更多语法支持，或者考虑集成专业的 Markdown 解析库如 `marked`。

### Q4: 能否支持多语言的更新日志？

A: 目前仅支持单一语言。未来可以通过检测 VS Code 语言设置，读取不同的 CHANGELOG 文件（如 CHANGELOG.zh-CN.md）。

### Q5: 更新通知会影响启动速度吗？

A: 版本检测是异步进行的，对启动速度影响极小。如果担心性能，可以在设置中禁用自动通知。
