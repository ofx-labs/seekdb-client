## 配置演示

### 禁用自动通知

用户可以在 VS Code 设置中禁用：

```json
// settings.json
{
  "seekdb.updateNotification.enabled": false
}
```

配置生效后：
- ✅ 插件更新时不再自动显示通知
- ✅ 仍可通过命令面板手动查看
- ✅ 其他功能不受影响

```

```

### Markdown 解析演示

输入（CHANGELOG.md）:
```markdown
### `v0.1.0` — 2025‑01‑26

#### ✨ New

- **版本更新通知**
  - 插件更新后自动展示更新日志
```

解析处理:
```
1. 识别标题: "### " → <h3>
2. 识别列表: "- " → <li>
3. 识别粗体: "**...**" → <strong>
4. 组合 HTML
```

输出（HTML）:
```html
<h3>v0.1.0 — 2025‑01‑26</h3>
<h4>✨ New</h4>
<li><strong>版本更新通知</strong></li>
<li>插件更新后自动展示更新日志</li>
```
